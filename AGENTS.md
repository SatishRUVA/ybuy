
# Mandatory UI/UX Design Workflow

For every UI/UX, frontend, page, component, or redesign task:

1. Read `.agents/skills/design-inspiration-researcher/SKILL.md`.
2. Discover all installed UI/UX-related skills using the available skill discovery mechanism.
3. Read and apply every relevant installed skill. Do not arbitrarily select only one when multiple skills apply.
4. Research external design references before implementation.
5. Do not use existing YBuy screens as visual inspiration. Existing code is for understanding functionality, business rules, routes, and APIs only.
6. Establish a fresh design direction, information architecture, user journeys, and component plan before coding.
7. Implement complete, responsive, interactive experiences—not isolated cosmetic patches.
8. Run a visual and functional quality audit after implementation.

Do not skip research because the task appears small. For small changes, perform proportionate research and still apply relevant skills.

Never claim a skill was used or a reference was inspected unless you actually read or accessed it.
